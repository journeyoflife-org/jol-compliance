## 1. Purpose

Defines security requirements for employees and contractors working outside Company premises, supporting ISO 27001 A.6.7, A.7.9 and GDPR Art. 32.

## 2. Eligibility

- Full-time employees with manager approval
- Contractors as defined in their engagement agreement
- Must complete remote work security training before first remote session

## 3. Network Security

- **VPN mandatory** for accessing internal systems from remote locations
- Public Wi-Fi: VPN must be connected before any Company system access
- Home networks: WPA2/WPA3 encryption required; default router passwords must be changed
- Split-tunnel VPN is not permitted for production access

## 4. Device Security

| Requirement | Details |
|------------|---------|
| Full-disk encryption | Mandatory on all remote devices (BitLocker/FileVault) |
| Endpoint protection | Company-approved antivirus/anti-malware must be active |
| Screen privacy | Privacy screen recommended when working in public spaces |
| Physical security | Device must not be left unattended in public or vehicles |
| Lost/stolen reporting | Report to IT within 1 hour of discovery |
| Updates | Operating system and applications must be kept current |
| USB drives | Encrypted USB drives only; unauthorised USB devices blocked |

## 5. Authentication

- MFA mandatory for all remote access
- Hardware security key recommended for privileged remote access
- VPN certificate-based or MFA-based authentication

## 6. Data Handling While Remote

- Confidential/Restricted data must not be stored on local device unless encrypted
- Use Company-approved file sharing (not personal cloud storage)
- Do not print Confidential/Restricted documents at home unless using a secure printer in a private location
- Securely destroy printed sensitive documents (cross-cut shredder minimum)

## 7. Physical Security While Remote

- Work area should be in a private or semi-private location
- Screen positioned away from unauthorised viewers
- Lock device (Win+L / Cmd+Ctrl+Q) when stepping away
- Do not allow family members or visitors to use Company devices

## 8. Communication Security

- Use Company email for all business communications
- Video calls: use Company-approved platforms with encryption
- Do not discuss Confidential/Restricted matters in public spaces
- Verify identity before sharing sensitive information by phone

## 9. Incident Reporting

Remote workers must report the following within the specified SLA:

| Incident Type | SLA |
|--------------|-----|
| Lost or stolen device | 1 hour |
| Suspected malware infection | 1 hour |
| Unauthorised access attempt | 4 hours |
| Data breach or suspected breach | Immediately (call CISO) |
