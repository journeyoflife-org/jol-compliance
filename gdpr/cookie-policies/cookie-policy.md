## 1. Introduction

This Cookie Policy explains how Journey Of Life UAB ("we", "us", "the Company") uses cookies and similar tracking technologies on the Journey Of Life platform ("Platform"). This policy complies with:

- **ePrivacy Directive 2002/58/EC** (as amended by 2009/136/EC)
- **GDPR (Regulation (EU) 2016/679)** — where cookies process personal data
- **National implementations**: Lithuanian Electronic Communications Act, Latvian Electronic Communications Act, Estonian Electronic Communications Act

---

## 2. What Are Cookies

Cookies are small text files stored on your device when you visit the Platform. We also use similar technologies:

| Technology | Description |
|-----------|-------------|
| **Session cookies** | Temporary; deleted when you close your browser |
| **Persistent cookies** | Remain on your device for a specified period |
| **First-party cookies** | Set by the Platform domain |
| **Third-party cookies** | Set by external services integrated into the Platform |
| **Local storage / session storage** | Browser storage used for preferences and state |
| **Web beacons / pixels** | Tiny images used to track interactions |

## 4. Consent Mechanism

### 4.1 Consent Banner

Upon first visit, users see a cookie consent banner with three options:

| Option | Effect |
|--------|--------|
| **Accept All** | Enables all cookie categories (Necessary + Functional + Analytics + Marketing) |
| **Reject Non-Essential** | Enables only Strictly Necessary cookies |
| **Customise** | Opens granular preference centre |

### 4.2 Consent Preference Centre

Users can manage preferences at any time via:
- Platform Settings → Privacy → Cookie Preferences
- Footer link: "Cookie Settings"

Granular controls per category:
- ☑ Strictly Necessary (always on, cannot be disabled)
- ☑ Functional cookies
- ☑ Analytics cookies
- ☑ Marketing cookies

### 4.3 Consent Recording

| Requirement | Implementation |
|------------|---------------|
| **Freely given** | Platform is fully usable with only necessary cookies |
| **Specific** | Separate consent per category (no bundled consent) |
| **Informed** | Plain-language description of each category before consent |
| **Unambiguous** | Explicit action (clicking "Accept") — no implied consent |
| **Withdrawable** | Users can withdraw consent at any time via preference centre |
| **Documented** | Consent records stored with: timestamp, categories, user ID, method |

### 4.4 Consent Renewal

| Trigger | Action |
|---------|--------|
| 12 months since last consent | Re-prompt consent banner |
| New cookie category added | Re-prompt for new category |
| New third-party provider added | Update cookie inventory; re-prompt if new category |
| User clears browser cookies | Re-prompt on next visit |

## 8. Withdrawal of Consent

### 8.1 Methods

| Method | Instructions |
|--------|-------------|
| **Preference Centre** | Platform Settings → Privacy → Cookie Preferences → toggle categories off |
| **Browser Settings** | Clear cookies via browser settings (note: may affect Platform functionality) |
| **DPO Request** | Email duomenu.apsauga@jol-hub.com to request withdrawal of all tracking |

### 8.2 Effect of Withdrawal

| Category | Effect of Withdrawal |
|----------|---------------------|
| **Functional** | Language/theme preferences reset; recent institutions list cleared |
| **Analytics** | No longer counted in usage statistics; existing aggregated data retained (anonymised) |
| **Marketing** | No longer receives personalised communications; existing campaign attribution data deleted within 30 days |

### 8.3 Withdrawal Processing Time

- Cookie deletion: **Immediate** upon preference update
- Server-side consent record update: **Within 24 hours**
- Third-party provider notification: **Within 72 hours**

## 9. Do Not Track (DNT) Signals

The Platform respects browser DNT signals:
- When DNT is enabled, all non-essential cookies are automatically disabled
- DNT does not affect strictly necessary cookies
- DNT preference is logged alongside other consent records
